# WI-00067 — v1.0.3 self-hosted-only release

## Goal

Publish one audited commit as `v1.0.3` through GitHub Release, PyPI and GHCR so default public artifacts contain only self-hosted guidance and no private Railway deployment endpoint.

## Authority

- Operator explicitly authorized this release cycle and all named public surfaces in session `S-01024`.
- ADR-003 remains product authority.
- `v1.0.2` remains immutable history and is not yanked; its GitHub release is marked superseded by `v1.0.3`.

## Bounded changes

1. Add and freeze `tests/test_v1_0_3_release_contract.py` before implementation.
2. Bump package/help version from `1.0.2` to `1.0.3`.
3. Add `scripts/verify-release-artifacts.py`, exercised against synthetic clean/leaking wheel and sdist fixtures, and invoke it from the existing tag release workflow.
4. Synchronize current-release documentation without changing product scope.
5. Do not change tool catalog, schemas, dispatch, transport, auth, corpus, transcript behavior or Railway configuration.

## Required evidence

- deterministic RED before production changes;
- independent pre-freeze contract audit PASS;
- Station frozen SHA-256 manifest;
- targeted GREEN and complete deterministic suite;
- wheel/sdist build, `twine check`, installed-wheel MCP initialize/help, Docker initialize/help;
- independent source/docs conformance PASS;
- hosted branch CI PASS before tagging;
- tag `v1.0.3` release workflow PASS;
- live PyPI, GitHub Release and GHCR `1.0.3`/`1.0`/`latest` receipts from the same commit;
- downloaded wheel/sdist and pulled image contain help version `1.0.3`, no `deploy_url`, and no private Railway hostname;
- after `v1.0.3` is live, preserve the existing `v1.0.2` release notes and append an explicit `Superseded by v1.0.3` notice with `gh release edit v1.0.2 --notes-file <bounded-file>`; verify through `gh release view v1.0.2 --json body,url` and record only the public body/URL in the live receipt. This external metadata action is not simulated by frozen tests.

## Secret and publication guardrails

- Never print or commit PyPI token, GitHub token, Railway Bearer key, proxy credentials or any private secret.
- Publication occurs only after frozen GREEN, hosted branch CI and independent audit PASS.
- Use the existing release workflow; do not upload manually unless the workflow fails for a separately audited infrastructure reason.
- Do not yank or delete historical PyPI files/tags/releases.

## Completion

WI-00067 closes only after all registry artifacts are live and independently match the audited commit. DIR-005 then returns to `done` with current Vision lineage.
