# tube-bridge v1.1.0

Self-hosted YouTube research release with 17 MCP tools and an Agent Plugin preview.

## Highlights

- `youtube_get_frame` returns one bounded ephemeral JPEG near an integer-millisecond timestamp.
- Default transcript selection stays within the video's default language family and prefers manual captions over generated captions in that family.
- Five local corpus tools provide semantic search over transcript chunks.
- The optional Agent Plugin bundle adds a research skill, examples, and reusable templates.

## Requirements

- Python 3.12 or newer;
- ffmpeg for frame extraction;
- optional user-provided YouTube Data API v3 key for comments and channel tools.

## Distribution

- PyPI: `pip install tube-bridge==1.1.0`
- Container: `ghcr.io/thewhitewater/tube-bridge:1.1.0`
- GitHub Release: wheel, source distribution, Agent Plugin ZIP, and checksums
