# tube-bridge v1.1.0

Self-hosted YouTube research release with 17 MCP tools and an Agent Plugin preview.

## Highlights

- **Timestamped visual inspection:** `youtube_get_frame` returns one bounded ephemeral JPEG as MCP `ImageContent` near an integer-millisecond timestamp.
- **Deterministic subtitle defaults:** omitted-language selection stays in the first ASR/default language family and cannot be captured by an unrelated foreign manual dub. Explicit `lang` remains the strongest provenance choice.
- **Agent Plugin preview:** one discoverable `tube-bridge-research` skill, a local stdio MCP manifest, research methodology, source-lineage and adversary gates, synthetic examples, reusable templates, and the frozen Corpus v2 storage contract.
- **17-tool runtime:** 14 tools are keyless-capable; 3 require an operator-owned YouTube Data API v3 key.

## Frame boundary

`youtube_get_frame` requires `ffmpeg` on `PATH`. Each call returns one JPEG only, with a public width range of 64–1280 pixels, raw JPEG limit of 1,500,000 bytes, and base64 limit of 2,000,000 characters. The temporary four-second clip is deleted before return. Metadata distinguishes the requested timestamp from the unmeasured actual source PTS (`actual_timestamp_ms: null`, `timestamp_accuracy: best_effort_frame_boundary`).

## Agent Plugin preview

Download `tube-bridge-agent-plugin-1.1.0.zip` from this release. Agent Plugins v1 does not standardize dependency installation, secrets, permissions, signatures, or a test harness. Prepare Python 3.12+, install the tube-bridge dependencies into the `python3` environment used by the host, and install ffmpeg separately.

The bundle contains no credentials. It is a local self-hosted capability, not hosted access.

## Corpus status

The released five corpus tools still use the v1 flat 80-second/20-second-overlap vector runtime in `corpus.db`. The plugin includes a reviewed **Corpus v2 storage contract** for future implementation—immutable timestamped source, versioned temporal projections, rebuildable lexical/dense indexes, and atomic generations—but this release does not claim that Corpus v2 is implemented.

## Upgrade notes

- The deterministic default transcript cache key changed from legacy `__any__` to `__default_v2__`; old ambiguous default-language entries are intentionally not reused.
- Existing explicit-language cache entries and v1 corpora remain compatible.
- Historical v1.0.x artifacts remain immutable and unyanked.
- The project remains MIT self-hosted-only. No public hosted demo, OAuth service, managed storage, accounts, or SLA is introduced.
