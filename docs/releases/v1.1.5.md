# tube-bridge v1.1.5

Public MCP metadata and discovery-quality patch.

## Changes

- publishes standard MCP `ToolAnnotations` for all 17 tools so clients can distinguish read-only, destructive, idempotent, local, and open-world operations;
- expands the descriptions of playlist, channel-upload, comment, and trending tools with explicit selection guidance, key requirements, result behavior, and upstream constraints;
- clarifies that `corpus_add` skips existing videos by default while `force_reembed=true` deletes and replaces that video's local chunks and vectors;
- adds schema-valid `glama.json` maintainer metadata for the claimed Glama profile;
- exposes the conservative weekly PyPIStats download metric in the README.

This patch does not add or rename tools, change input schemas or successful response schemas, alter typed-error payloads, introduce a hosted service, or change the self-hosted product boundary. Glama performs its own asynchronous analysis; this release does not guarantee a particular Glama score.

The official Registry identity remains `io.github.TheWhiteWater/tube-bridge`.

## Distribution

- PyPI: `pip install tube-bridge==1.1.5`
- Container: `ghcr.io/thewhitewater/tube-bridge:1.1.5`
- GitHub Release: wheel, source distribution, Agent Plugin preview, and checksums
