# tube-bridge v1.1.1

Patch release improving Corpus v1 result quality and compatibility.

## Changes

- suppresses overlapping chunks from the same video in returned results;
- limits source domination with deterministic per-video caps and refill;
- returns cached titles and canonical YouTube timestamp URLs;
- validates `top_k` in the public 1–50 range;
- uses collision-resistant vector-table names;
- migrates legacy colliding tables transactionally;
- preserves unrelated vectors during `force_reembed`.

Similarity scores are ranking signals, not confidence or evidence-quality measurements.

## Compatibility

Existing `corpus.db` files migrate additively. Cached titles remain nullable and best effort. Tool names, the embedding model, and the 80-second window with 20-second overlap are unchanged.

## Distribution

- PyPI: `pip install tube-bridge==1.1.1`
- Container: `ghcr.io/thewhitewater/tube-bridge:1.1.1`
- GitHub Release: wheel, source distribution, `tube-bridge-agent-plugin-1.1.1.zip`, and checksums
