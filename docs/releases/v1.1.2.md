# tube-bridge v1.1.2

Metadata-only release for official MCP Registry discovery.

## Registry publication

- Registry name: `io.github.TheWhiteWater/tube-bridge`
- Distribution: PyPI package through `uvx`, using stdio transport
- Optional configuration: user-owned YouTube Data API key, proxy URL, and local cache directory
- Publication authentication: GitHub Actions OIDC; no dedicated Registry secret

This release adds `server.json`, package-ownership metadata, an OCI ownership label, and checksum-pinned Registry publishing automation. It makes no MCP tool or runtime behavior changes.

## Distribution

- PyPI: `pip install tube-bridge==1.1.2`
- Container: `ghcr.io/thewhitewater/tube-bridge:1.1.2`
- GitHub Release: wheel, source distribution, Agent Plugin preview, and checksums
