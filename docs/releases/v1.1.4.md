# tube-bridge v1.1.4

Typed MCP tool errors and a bounded stderr-safety correction.

## Changes

- returns controlled tool failures as `CallToolResult(isError=True)` instead of successful MCP envelopes containing JSON error text;
- preserves the top-level `error` string while adding stable `code`, `source`, and `retryable` fields;
- includes `retry_after_seconds` only when a valid upstream `Retry-After` value is available;
- preserves ordinary successful responses and successful YouTube Data API to yt-dlp fallback behavior;
- classifies YouTube Data API, yt-dlp, transcript, frame, and local corpus failures without message parsing by clients;
- uses yt-dlp stderr for internal failure classification without exposing raw yt-dlp stderr in MCP error payloads.

This patch does not add tools, change successful response schemas, introduce a hosted service, or alter Corpus v1 search behavior.

The official Registry identity remains `io.github.TheWhiteWater/tube-bridge`.

## Distribution

- Container: `ghcr.io/thewhitewater/tube-bridge:1.1.4`
