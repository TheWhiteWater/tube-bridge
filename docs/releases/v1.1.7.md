# tube-bridge v1.1.7

Multi-platform container release for the existing self-hosted server.

## Changes

- publishes `ghcr.io/thewhitewater/tube-bridge` for `linux/amd64` and `linux/arm64` under one tag, so Docker pulls the right image automatically;
- builds and verifies each platform on a native runner: dependency check, real CPU embedding, `sqlite-vec` query, H.264 and JPEG through ffmpeg, health, authentication, and the MCP tool list;
- runs the full test suite on arm64 in CI, and publishes to PyPI only after the container release succeeds;
- adds an official MCPB manifest and a deterministic bundle builder;
- adds an experimental research artifact preview. It stays off unless you set `TUBE_BRIDGE_EXPERIMENTAL_RESEARCH_ARTIFACTS=1`, and may change without notice;
- adds a project logo and a short request to star the repository.

The default runtime still exposes the same 17 MCP tools. This release does not add a hosted service.

On a Raspberry Pi, use a 64-bit OS: 32-bit Raspberry Pi OS, ARMv6, and ARMv7 are not supported. The arm64 image is verified on CI runners and under emulation, but it has not been tested on physical Raspberry Pi hardware yet.

The official Registry identity remains `io.github.TheWhiteWater/tube-bridge`.

## Distribution

- PyPI: `pip install tube-bridge==1.1.7`
- Container: `ghcr.io/thewhitewater/tube-bridge:1.1.7`
- Pi: `pi install git:github.com/TheWhiteWater/tube-bridge@v1.1.7`
- GitHub Release: wheel, source distribution, Agent Plugin preview, and checksums
