# tube-bridge v1.1.6

Native Pi packaging patch for the existing self-hosted capability package.

## Changes

- adds a native Pi package manifest and package-relative adapter alongside the existing Agent Plugins v1 manifest, MCP configuration, runtime, and canonical `tube-bridge-research` skill;
- lets Pi install the immutable Git source with `pi install git:github.com/TheWhiteWater/tube-bridge@v1.1.6` and discover one status tool plus all 17 MCP tools;
- derives the Pi launch command, working directory, and version from the canonical `mcp.json`, `plugin.json`, and package root rather than a separate machine-local integration;
- preserves bounded text, MCP image content, typed tool failures, reconnect/self-test commands, lifecycle cleanup, and an allowlisted child-process environment;
- adds Python 3.12/3.13 CI coverage for the real Pi-to-stdio MCP handshake and the complete 17-tool catalog.

The Pi package manager installs the Node adapter dependency but does not install Python or ffmpeg. Those runtime prerequisites remain explicit operator responsibilities, as they are for the Agent Plugin preview. This release does not add or rename MCP tools, change input or successful response schemas, expand Agent Plugins v1 dependency-bootstrap claims, introduce credentials, or introduce a hosted service.

The official Registry identity remains `io.github.TheWhiteWater/tube-bridge`.

## Distribution

- PyPI: `pip install tube-bridge==1.1.6`
- Container: `ghcr.io/thewhitewater/tube-bridge:1.1.6`
- Pi: `pi install git:github.com/TheWhiteWater/tube-bridge@v1.1.6`
- GitHub Release: wheel, source distribution, Agent Plugin preview, and checksums
